# ADR-006: Отказ от P2P, honeypot, sandbox — записано как future work

## Контекст

Ранняя формулировка проекта (`docs/README.md` до этого ADR) описывала более широкую
систему: «автоматическое реагирование (iptables, honeypot, песочница)». Ни один из этих
трёх элементов не реализован и не начат ни в одном репозитории; текущая архитектура
(`docs/architecture/system.md`) их не предполагает даже в целевом (не реализованном
ещё) виде. Разрыв между описанием и фактической системой достаточно большой, чтобы
формально зафиксировать: это не забытые пункты бэклога, а осознанно отложенное вне
рамок диплома направление.

## Решение

Следующие направления не входят в объём работы, ведущей к защите диплома, и не
планируются как часть текущей целевой архитектуры:

- **P2P** между сенсорами (обмен данными или решениями напрямую между агентами, минуя
  control plane) — вся координация идёт через backend/control plane (ADR будет описан
  отдельно, когда control plane закроет desired/actual config, сейчас см.
  `docs/architecture/system.md`), агенты друг с другом не взаимодействуют.
- **Honeypot** — отдельная приманка-сервис для привлечения и изучения атакующих.
- **Sandbox** — изолированное исполнение подозрительных образцов (файлов, скриптов).

Iptables как исполнительный механизм реагирования отклонён отдельно, в ADR-001, в
пользу eBPF-дропа внутри уже загруженных программ.

## Последствия

- `docs/README.md` переписан вслед за этим ADR, чтобы не обещать функциональность,
  которой нет и не будет к защите — расхождение между README и реальной системой было
  главной причиной написать этот ADR.
- Если проект продолжится после защиты как что-то большее, чем дипломная работа, любое
  из этих трёх направлений может быть пересмотрено — это ADR о текущем объёме, а не
  запрет менять решение навсегда.

## Отвергнутые варианты

Формально альтернативой самому этому ADR было бы не фиксировать отказ явно, а просто
молча не делать эти три пункта. Отклонено: без явной записи растущий разрыв между
README (обещание) и фактической системой (что реально есть) не имеет объяснения ни для
рецензента диплома, ни для нового участника проекта, читающего `docs/README.md` как
точку входа.
